## 6. Lệnh nghiệm thu trên Windows

Mở PowerShell ở thư mục dự án CP24, với `.env.local` chỉ trên máy của bạn:

```powershell
npm ci
npm run verify:cp24
```

Nếu muốn kiểm tra trước các lệnh mà không chạy:

```powershell
node tools/verify-cp24.cjs --plan
```

Lệnh nghiệm thu chạy tuần tự: layout, 53 Node, 15 Rules tĩnh, API typecheck, production build, 42 case Emulator qua workspace ASCII. Báo cáo trạng thái lưu tại `docs/checkpoints/CP24_VERIFY_LOCAL.json` (chỉ mã trạng thái, không lưu nhật ký dữ liệu cá nhân). Chỉ khi đủ PASS và E2E riêng được xác nhận mới xem xét phát hành.
