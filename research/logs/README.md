# Research logs

Create append-only entries before and after each analysis run:

- `research_decision_log.csv`: decision, rationale, owner, date, protocol version, whether pre/post-outcome.
- `negative_result_log.csv`: attempted method, expected result, observed result, reason for failure, follow-up.
- `ai_usage_log.csv`: tool/model, purpose, input scope, generated artifact, human verification, date.
- `contribution_log.csv`: contributor, task, artifact, commit/hash, review/approval.

Do not invent contributors, approvals, sample sizes or outcomes. Keep the logs empty until a real entry is available.
