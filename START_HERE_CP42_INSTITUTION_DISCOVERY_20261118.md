# CP42 — Institution discovery and national source queue (2026-11-18)
Base: CLA_FULL_SOURCE_CP42_SCHEME_RECONCILIATION_20261118.zip. Student-only, chart-first. No production deployment, provider activation, or rules change.

## New functionality
- Atlas NationalSourceDiscoveryPanel includes an expandable searchable, paginated directory with source-status filter and stacked source-status bar. Selecting a school fills the existing public query, resets confirmation, focuses the input, and requires explicit user confirmation before the three-year lookup. Supports names with/without Vietnamese accents, and existing registry codes/aliases. Unknown schools/fields remain free-text searchable. No browser storage or automatic aspiration/cutoff creation.
- Institution name source: Ministry survey attachment October 2026, hosted by HUBT, https://hubt.edu.vn/wp-content/uploads/CV-370.pdf, printed pages 2–4 (99 names). Manual transcription from accessible PDF text, screenshot fetches failed (cache miss). The document is a survey participant list, NOT an official admissions unit/code register; includes parent universities and a research academy. No survey responses or personal information imported. Explicit manual name-to-registry crosswalk by source row (23 links) only, not campus or code mapping. Not independently audited. No inferred school codes or official portals for discovery-only entries.
- Union: 99 source names + 9 registry entries not in survey = 108 distinct discovery entries, 32 linked to existing admissions source registry, 76 discovery-only. Those 76 have no grade/major/cutoff eligibility claim. Exact directory-name lookups return sources only for the crosswalk identity, never borrow from same-name schools or member schools. Parent units and children remain separate. Coverage chart is local scope only. Existing 1,372 numeric cutoff records, 579 programmes, 373 combination-source entries unchanged.
- `npm run research:atlas:coverage` now generates discovery metadata and 228 source review tasks (76 names x 2024–2026), for finding and reviewing, NOT a set of verified admissions publications. Local audit remains separate, and the optional operator-reviewed Ministry inventory remains supported. No national denominator. Ministry admissions portal returned 403 in web fetch, no independently complete list available.
